# first_step_React_Native

This is my first step to React Native course. I am starting learning React Native — this is my first course!

## Getting Started

This project was bootstrapped with [Expo](https://expo.dev).

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Expo Go](https://expo.dev/go) app on your mobile device (optional)

### Installation

```bash
npm install
```

### Running the App

```bash
# Start the Expo development server
npm start

# Run on Android
npm run android

# Run on iOS (macOS only)
npm run ios

# Run on Web
npm run web
```

## Project Structure

```
├── App.js          # Main application component
├── app.json        # Expo configuration
├── assets/         # Images, fonts and other static files
├── index.js        # App entry point
└── package.json    # Project dependencies
```
